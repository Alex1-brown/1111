# Быстрый запуск — Earth System Trend Detective

## Windows 10/11

1. Откройте репозиторий GitHub и скачайте ZIP-архив через Code → Download ZIP. Распакуйте его в обычную папку.
2. Установите Python 3.12 или новее, если он ещё не установлен.
3. Подключите интернет и дважды нажмите START_HERE_WINDOWS.bat.
4. При первом запуске программа создаст отдельную среду .venv и установит зависимости. При обычных следующих запусках пакеты повторно не загружаются.
5. В окне оставьте координаты Душанбе или введите другую широту и долготу. Нажмите «Запустить анализ».
6. После завершения откроется artifacts/report.html. В отчёте доступны переключение EN/RU, графики и интерактивная сетка пикселей NDVI.

Если requirements.txt был изменён, удалите файл .venv\requirements-installed.flag и повторите запуск. Если первая установка оборвалась, удалите папку .venv и запустите BAT-файл снова.

## Источники и период

- NASA MODIS/Terra MOD13Q1.061: количественный NDVI и слой качества пикселей за 2001–2025 годы.
- NASA POWER: дневная температура воздуха на высоте 2 м и скорректированные осадки за 2021–2025 годы.
- Исследуемая область: примерно 4 × 4 км вокруг заданной точки.

Обычные цветные изображения GIBS в стандартном запуске отключены: это обзорные изображения, а не калиброванные спектральные измерения. Основной анализ растительности выполняется по количественному продукту MODIS NDVI.

## Результаты

- report.html — интерактивный отчёт, который можно открыть локально и без интернета после сбора.
- report.json — параметры, источники, результаты и научные ограничения.
- charts — графики SVG.
- modis_ndvi/ndvi_spatial_trends.csv — описательные оценки наклонов Сена по пикселям.
- modis_ndvi/ndvi_spatial_trends.geojson — пространственные точки для GIS-программ.
- CSV-сводки за год, месяц и сезон.

## Научные ограничения

NASA POWER предоставляет сеточные оценки, а не показания местной метеостанции. NDVI характеризует зелёность растительности, а не температуру, осадки или биомассу напрямую. Выводы относятся к локальному окну, а не ко всему Таджикистану. Корреляция не доказывает причинность.

Проверки текущих вариантов поправки на временную автокорреляцию выявили проблемы калибровки. Их p/q и интервалы в проекте используются только как диагностические показатели; наклоны Сена следует читать как описательные оценки направления и величины. Проверка Landsat 8/9 является сравнением согласованности сенсоров, а не наземной истиной; в QA-v3 наборе осталось девять пригодных лет и номинальный тест не показал значимый тренд на уровне 0,05.

## Требования

Windows 10/11, Python 3.12+, интернет для установки библиотек и скачивания данных. После генерации отчёт можно просматривать офлайн.
