# Веб-интерфейс Earth System Trend Detective

Это браузерная оболочка над существующим научным конвейером `science_core.cli`. Она не подменяет вычисления демонстрационными значениями: кнопка запускает Python-процесс, который получает NASA POWER и MODIS NDVI, а затем формирует исходный HTML-отчёт.

## Локальный запуск (Windows / Linux)

Требуется Python 3.12+ и интернет для установки зависимостей и загрузки данных.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
python -m pip install -r requirements-web.txt
python web_app.py
```

Откройте http://127.0.0.1:8000 . Укажите широту/долготу и нажмите **Run NASA analysis**. Журнал обновляется автоматически. По завершении откройте научный HTML-отчёт.

## Docker

```bash
docker build -f Dockerfile.web -t earth-system-web .
docker run --rm -p 8000:8000 earth-system-web
```

## Развёртывание

Для хостинга нужен сервис, который запускает Python и имеет исходящий HTTPS-доступ к NASA POWER и Microsoft Planetary Computer. GitHub Pages сам по себе не запускает Python backend. Vercel не используется.

Ветка содержит подготовленный Dockerfile; перед публичным развёртыванием обязательно добавьте аутентификацию, лимиты запросов, ограничение времени/памяти и изоляцию задач. Текущая версия рассчитана на локальный или доверенный одиночный тест: один процесс анализа за раз, состояние задач хранится в памяти, серверный отчёт доступен тому, кто может обратиться к сервису. Не выставляйте её в открытый интернет без защиты.

## Научные ограничения

- NASA POWER — сеточные оценки, а не локальная метеостанция.
- MODIS NDVI — индикатор растительности, не температура воздуха и не доказательство причинности.
- Проектные проверки автокорреляции не позволяют трактовать диагностические p/q значения как доказательство статистической значимости.
- GPM IMERG не загружается этим веб-запуском; основной путь использует NASA POWER и MODIS NDVI.
